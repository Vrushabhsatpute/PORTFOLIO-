# Vrushabh Satpute Portfolio - Local Setup Guide

This folder contains the complete source code for the single-page personal portfolio.

## Files
- `index.html`: The main website file (contains all HTML, CSS, and JavaScript).

## How to Run Locally in VS Code

1. **Download and Extract**: Download the `vrushabh_portfolio.zip` file and extract it to a folder on your computer.
2. **Open in VS Code**:
   - Open VS Code.
   - Go to `File` > `Open Folder...` and select the extracted `vrushabh_portfolio` folder.
3. **Install "Live Server" Extension** (Recommended):
   - Click on the **Extensions** icon in the left sidebar of VS Code (or press `Ctrl+Shift+X`).
   - Search for **"Live Server"** by Ritwick Dey.
   - Click **Install**.
4. **Start the Website**:
   - Open the `index.html` file in the editor.
   - Right-click anywhere inside the code and select **"Open with Live Server"**.
   - Alternatively, click the **"Go Live"** button at the bottom-right corner of the VS Code window.
5. **View in Browser**: The website will automatically open in your default browser at `http://127.0.0.1:5500/index.html`.

## Alternative (No Extension)
If you don't want to install an extension, you can simply **double-click** the `index.html` file in your computer's file explorer to open it in any web browser. However, using a local server (like Live Server) is better for testing animations and external scripts.
